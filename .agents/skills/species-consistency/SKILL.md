# Species Consistency

Use when a world or task requires factual synchronization across species-related entries.

## Workflow

1. Resolve the target world and read active profiles.
2. Identify the species/type and all affected entries.
3. Compare factual claims across NPC types, traits, world lore, NPCs, and abilities.
4. Distinguish factual inconsistency from appropriate audience-specific prose.
5. Report required decisions and proposed fixes; do not edit unless separately approved.

## Rule

Require factual consistency, not identical prose across fields with different audiences.
