# Templates

Reusable Voyage world starter files.

- `minimal-world.json` is a complete minimal compiled Voyage config.
- `tabs/` is the same minimal world split into the tab layout used by the tooling.

World instances declare their tabs and compiled output in `.world-puppeteer.json`. The repository-root reference world now builds to `HxH-Full-Canon-Reference.json`, while this template keeps `minimal-world.json`.
